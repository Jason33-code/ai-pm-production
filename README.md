## 项目一：参考 OpenClaw 的招聘与合同比对工作流

计划构建：岗位需求输入、简历解析、证据匹配、人工复核、邀约草稿及状态记录；合同模块支持版本对齐、文字差异、原文定位和人工复核。

- [ ] 明确用户问题、流程和验收标准
- [ ] 使用模拟或获得授权的数据建立测试集
- [ ] 实现单次模型调用基线
- [ ] 实现证据定位、需求版本管理和重复操作防护
- [ ] 评测证据正确率、无依据判断率、变更更新正确率及复核耗时
- [ ] 保存真实运行日志、个人演示和评测报告

招聘结论用于辅助人工复核；缺失信息与不满足要求分别呈现。合同的法律风险结论需专业复核。

## 项目二：参考 PandaToken 的模型 API 质量评测工具

计划构建：平台配置、测试任务执行、流式响应记录、异常分类、指标报告与接入建议。

- [ ] 定义统一请求、模型版本、输入长度、并发与预算
- [ ] 实现成功率、首个有效文本返回耗时、总耗时与用量记录
- [ ] 检查流式输出、结构化输出和工具调用协议
- [ ] 用模拟接口验证超时、限流和异常响应处理
- [ ] 对授权接口开展有限预算的真实测试
- [ ] 用 Python 汇总指标，用 SQL 分析平台、任务和错误类型
- [ ] 发布样本量、测试环境、P50/P95、失败明细及局限

响应中的 model 字段仅能检查标识一致性，不能证明底层模型真实身份。无真实测试前，不发布排名、提升幅度或接入收益。
